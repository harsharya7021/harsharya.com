How do I make a key?
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained → Generate new.
  2. Resource owner harsharya7021 · Repository access → Only select → harsharya.com.
  3. Permissions → Contents → Read and write. Generate, copy, paste above.
  4. Keep a copy in your password manager. The key stays only on this device.

Where do I get the token?
  1. Sarvam has never opened cloned voices to API keys — the public TTS API only takes stock speakers, and the voice-library endpoint answers a key with 401 authentication required. Checked again July 2026: unchanged.
  2. Your logged-in browser does hold a credential that reaches it. Open studio.sarvam.ai, DevTools → Network, generate one line of speech with your cloned voice, click the synthesize request, and copy the Authorization header value.
  3. Paste it above and hit Use my cloned voice — it's stored on your box only (data/sarvam.json, never in git, never in this browser) and tested immediately.
  4. Browser tokens expire. When one does, narration quietly falls back to the stock speaker and says so — grab a fresh header and re-paste.
